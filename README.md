# Telecom Churn Intelligence

An end-to-end telecom churn prediction and retention platform. A trained ML model scores each customer's churn risk, a LangGraph agent pipeline generates a plain-English explanation and ranked retention offers using Gemini, and SHAP provides feature-level explainability — all served through a role-based React dashboard.

## Features

- **Churn prediction** — Random Forest / Gradient Boosting / Logistic Regression trained on Telco dataset; best model selected by ROC-AUC
- **LangGraph agent pipeline** — `score → explain → recommend` graph with conditional routing (Gemini called only for high/medium risk)
- **SHAP explainability** — per-customer feature-level SHAP values via `POST /shap`
- **Retention offers** — up to 3 ranked offers (High / Medium / Low priority) generated by Gemini with rule-based fallback
- **Role-based access** — three roles: `admin`, `employee`, `customer` — each sees a different dashboard
- **Prediction history** — every prediction stored with factors, summary, and offers snapshot
- **Interaction tracking** — support/complaint history per customer
- **Admin auto-seeded** — admin account created automatically on first backend startup

## AI Pipeline — LangGraph

```
[score] ──→ risk: high/medium ──→ [explain_gemini]   ──→ [recommend_gemini]   ──→ END
        └─→ risk: low         ──→ [explain_fallback] ──→ [recommend_fallback] ──→ END
```

- **score** — classifies probability into `high / medium / low`
- **explain_gemini** — Gemini writes a 2-3 sentence plain-English explanation
- **explain_fallback** — rule-based summary for low-risk customers (no API call)
- **recommend_gemini** — Gemini generates personalised retention offers (JSON)
- **recommend_fallback** — rule-based offer catalogue for low-risk customers

## ML Model

**Dataset** — IBM Telco Customer Churn (`ai/data/raw/telco_churn.csv`)

**Features:** `tenure`, `MonthlyCharges`, `TotalCharges`, `Contract`, `InternetService`, `PaymentMethod`, `TechSupport`, `OnlineSecurity`, `OnlineBackup`, `DeviceProtection`, `StreamingTV`, `StreamingMovies`, `PaperlessBilling`, `gender`, `SeniorCitizen`, `Partner`, `Dependents`, `MultipleLines`

**Engineered:** `AvgMonthlyCharges`, `TenureGroup`, `TotalServices`

**Models trained:** Logistic Regression, Random Forest, Gradient Boosting — best selected by ROC-AUC

**Retrain:**
```bash
cd ai && python model/train.py
```

## CI/CD

GitHub Actions (`.github/workflows/ci-cd.yml`):

1. **Test AI** — installs Python deps, smoke-tests imports

3. **Build Frontend** — `npm ci` + `npm run build`
4. **Build & Push** — Docker images pushed to AWS ECR (main branch only)
5. **Deploy** — SSH into EC2, pulls latest images, runs `docker compose up -d`

## Infrastructure (Terraform)

Provisions: VPC, public subnet, internet gateway, security group, Elastic IP, EC2 (Ubuntu 22.04, **t3.micro**, **30 GiB gp2** — AWS free tier eligible), 3 ECR repositories.

```bash

export TF_VAR_gemini_api_key="your_gemini_key"
export TF_VAR_mongo_uri=""
export TF_VAR_db_password="Admin@123"

cd terraform
terraform init
terraform plan
terraform apply -auto-approve
```

```
frontend_url = "http://<public_ip>"
backend_url  = "http://<public_ip>:8080"
ssh_command  = "ssh -i ~/.ssh/id_rsa ubuntu@<public_ip>"
```

**To destroy (avoid charges):**
```bash
terraform destroy -auto-approve
```

> **Free tier:** t3.micro = 750 hrs/month free (first 12 months). 30 GiB gp2 = free tier storage limit. Always destroy when not in use to avoid Elastic IP charges.
